# 1 Trillion

A small offline app: your total money, a green box to add, a red box to deduct, and a line chart (daily, weekly, monthly).

Everything you enter is saved only on your phone. Nothing is sent anywhere.

Open https://kaliramvy.github.io/1-trillion/ in Chrome on your phone, then use the menu (⋮) → **Add to Home screen** / **Install app**.
